# 导播控制台与 OBS 输出使用说明

C++ 主服务器为 0.4.1，导播服务为 0.8.0；HOOK 0.3.2、采集器 0.1.5 保持单文件注入与 1 Hz。账号、订阅和本地控制接口详见 [浏览器协议](../protocol/browser-v1.md)。

## 本机启动

先按 [主服务器运行说明](server.md) 构建并配置网络。新增 OpenSSL 3.x 构建依赖，当前 Windows GCC 使用静态链接；发布目录附 OpenSSL 许可证。导播需要 Node.js 24 或以上，不需要 npm 安装依赖。

在项目目录执行：

```powershell
# 首次创建账号；密码交互输入，不放命令行。
python tools/accounts.py set --username director --role director --instance dcs-local

# 主服务必须在创建 users.json 后启动，已运行的旧版本先 Stop 再 Start。
./tools/Server.ps1 Start
./tools/Director.ps1 Start -Port 9170
```

打开 `http://127.0.0.1:9170/`，输入刚才设置的账号密码。默认生成「比赛直播」「紧凑阵容」两个独立画面。

每个画面可以选任务、飞机与导弹，调整功能开关、阵营、玩家过滤、搜索、排序、单位、赛事标题/队名/人工比分、事件类型、透明背景与安全边距。「组件与数据开关」中的十六项开关切换后立即更新预览和 OBS，并自动保存到当前画面；其他字段仍点击「保存」后生效。实时开关不会连带提交其他未保存字段。未保存内容切换画面前需要保存或点击还原，避免悄悄丢失更改。

组件显示/隐藏使用 220ms 淡入淡出与轻微位移动画，快速反向切换会中断旧动画并采用最终状态。常规遥测刷新不重启动画，系统开启「减少动态效果」时直接切换。开关写入失败或版本冲突会恢复当前已保存的开关并提示错误；其他草稿继续保留。

复制画面会创建独立 ID 与只读密钥，不与原画面共用配置。两控制页同时编辑时旧 revision 返回冲突，页面保留未保存内容。

在 OBS 添加「浏览器」源，宽 1920、高 1080，粘贴「复制 OBS 地址」得到的完整地址（包括 # 后内容）。默认开启透明背景，将浏览器源放在 DCS 游戏捕获上方，中央透出游戏画面。输出页只读，不能编辑配置；地址包含该单画面的读取权限，只交给需要该输出的人。

同一台机器可运行第二个独立服务：

```powershell
./tools/Director.ps1 Start -Port 9171
./tools/Director.ps1 Status -Port 9171
./tools/Director.ps1 Stop -Port 9171
```

配置位于 runtime/director-端口/账号命名空间/outputs.json，原子保存。服务重启、主服务器重启或 8 小时会话过期后重新登录；同账号仍得到之前的输出与 OBS 地址。不同账号隔离保存；退出登录时输出停止读取。

## 账号管理

在主服务机器执行 `python tools/accounts.py list` 查看不含密码的列表；`set` 可修改角色、授权实例，带 `--password` 时提示新密码；`disable` 禁用账号。文件改变后，运行中的服务在约一秒内撤销该账号旧会话。默认不开放注册。

```powershell
python tools/accounts.py set --username director --role director --instance dcs-local
python tools/accounts.py set --username observer --role viewer --instance dcs-local
python tools/accounts.py set --username director --password
python tools/accounts.py disable --username observer
```

admin 可读取运维状态，director 可管理自己本地服务的画面，viewer 只能查看自己的输出和授权源。账号文件管理需要主服务机器的文件权限，不提供匿名账号管理入口。

## 异机导播与 TLS

主服务 TCP 上传及普通 HTTP 仍绑定回环。异机访问启用独立 HTTPS/WSS 端口，证书必须包含实际访问的 DNS 名或 IP。不要将 HTTP 运维端口直接暴露给远端。

在 runtime/server/config.json 原有字段上增加：

```json
{
  "tlsPort": 9443,
  "tlsBind": "192.168.1.10",
  "tlsCertificate": "runtime/server/tls/server-chain.pem",
  "tlsKey": "runtime/server/tls/server-key.pem"
}
```

保留原有 instanceId、端口和 token 字段。重启主服务使监听配置生效。配置文件变化不会自动修改系统防火墙；按实际局域网部署范围放行所选 TLS 端口。

导播电脑复制 dist/director，安装 Node.js 24，执行：

```powershell
# 私有 CA 时在启动 Node 前指定受信任 CA 文件；公共受信任证书无需该环境变量。
$env:NODE_EXTRA_CA_CERTS = 'C:\DcsDirector\ca.pem'
node src/director/server.mjs --port 9170 --data-dir runtime/director --upstream https://dcs-host.example:9443
```

普通远端 HTTP 地址会被拒绝。没有关闭证书校验的选项。服务仍只在导播机器的回环地址提供网页，控制浏览器与 OBS 均连接本机。

## CS 式选手 HUD

顶部显示赛事与比分，两侧显示双方选手卡，底部显示导弹摘要。血量条改为油量条；选手卡包含玩家名或 AI 呼号、机型、速度、高度、油量与挂载。小地图、导弹条与事件播报均贴边。标准布局每侧 5 张卡，紧凑布局每侧 8 张卡。

16 个独立开关：比赛信息、战术小地图、两侧选手卡、导弹追踪、事件播报、链路状态、油量、速度、高度、挂载、队标、小地图导弹名称/发射人、来袭图标及其名称/发射人。棋盘格预览代表透明区域，OBS 输出不含棋盘格。

旧配置缺少新增四个数据开关时自动补为开启，原开关不变；当前布局 ID 为 overview/tactical，旧 focus 自动迁移，输出 ID 与链接不变。本机此次部署更新旧预置名称并开启透明背景，备份保留在原配置旁，其他过滤与赛事设置保留。

## 数据口径与显示

- 速度来自 DCS 世界速度矢量的三维模长，并非座舱指示空速。油量为内部容量基准的 API 原始比例，可超过 100%。
- 挂载展示 DCS 可查询的弹药类型/数量，不承诺挂点或吊舱布局；未知与空列表不同。
- 地图使用 DCS 本地坐标绘制态势网格与目标关系，不加载地理底图。密集标签自动避让。过期位置降低亮度。
- 阵容过长时每 12 秒轮换分页；导弹列表同样轮换，指定导弹优先。各页显示总数和页码。
- 结束后保存的是历史快照；未在当前快照出现不能推定被击落。暂停、连接中断与任务结束分开显示。
- 新登录获取的历史事件不触发播报；实时事件按序号去重，记录区保留最近历史。跟踪结束与击杀事件严格区分。
- 采集完整、服务器收齐、历史仍保留、任务环境 ACK 清理是不同事实。`unverified` 不表示服务器丢了尾部，也不宣称任务环境清理已验证。

## 选手池、队伍与标牌（0.5.0）

在「分队与选手池」选择模式：

- **DCS 红蓝阵营**：按当前飞机阵营自动分组。选手池绑定玩家名称，重进飞机自动跟随最新飞机；未入池飞机仍可按过滤条件显示。未知阵营暂列左侧。
- **自定义队伍**：两个独立选手池分别代表左队、右队。选手的归属完全由手动分队决定，忽略 DCS 红蓝阵营过滤；未入池的飞机不出现在两侧阵容中。队名和整数比分在「赛事信息」设置。比分不由死亡事件自动加减。

输入或选择 DCS 玩家名称，点击「加入选手池」。玩家按名字精确匹配，同一玩家不能同时加入两池；同名在线玩家冲突时不猜测身份。重命名的玩家需重新绑定。两种模式共享池名单，切换模式不会丢失手动队伍归属。

每队可上传 PNG / JPEG / WebP 队标，输入不超过 5 MB，浏览器优先保留最长边 1024 像素，在 75 KB 预算内压缩后内嵌保存。透明 PNG 可保留透明背景。队标默认位于比分栏内，可选「左队队标 / 右队队标」独立设置 Dock，也可在编辑预览中拖动。全局「队标」开关实时生效。

标牌支持统一模板和单张覆盖：选手名、单位名、机型、身份、阵营/队伍、油量、速度、高度、挂载、序号。选手覆盖优先于飞机覆盖；未覆盖字段继续继承。全局油量/速度/高度/武器开关仍是总开关。宽度 240～520、缩放 50～150%。每侧同时显示 0～16 张；超额可按 3～120 秒轮换。身份、机型、武器、油量百分比、速度 km/h、高度 m 可筛选；启用数值条件时未知数据不当作零。

「切换预览拖动」开启编辑手柄，可拖动组件、标牌、选手席位和队标。位置以 1920×1080 为基准，在缩小预览中仍能准确换算，吸附边缘、中心或其他组件边线。也可直接填九种基准位置与偏移。自由拖出的标牌和固定 Dock 独立于两侧分页，不占数量配额。大尺寸/高数量可能占据中央画面，请在预览中调整；默认布局仍为游戏画面留空。

点击「固定飞机席位」新增占位，选择单位名或把飞机标牌拖入该席位即可绑定。选手池席位也可独立 Dock；恢复自动位置后回到所属队伍。最多 32 个固定/选手席位。崩溃、死亡、被击杀或选手断开 DCS 时保留标牌，显示带斜线的飞机死亡标识及原因，不显示过期的油量和速度。离开飞机、转观战、对象暂缺、HOOK/Web 断连均不凭空判死。选手绑定重新进入飞机后跟随当前飞机；单位名绑定保持该飞机席位。

死亡事实在本地导播的每个任务源内保留，不依赖 200 条播报窗口；页面刷新、事件滚出播报窗口不会清除。缓存最多 512 个飞机生命周期，优先保留当前对象。导播退出登录、重启、切离不再订阅的任务源或主服务器重启后，超出上游历史窗口的旧事实无法保证恢复。比赛进行中应保持导播服务运行。

断线来自 `onPlayerDisconnect`，连接/座位信息由 `net.get_player_list/get_player_info` 每秒读取。DCS 官方本机 `API/Sim_ControlAPI.md` 说明该回调不针对 Hook 所在客户端自身；应让观战客户端/服务器 Hook 观察比赛选手，不将本机 Hook 消失直接当成选手断线。此版本已用 Lua 模拟和真实 C++/浏览器协议测试断线、重进、死亡保留，尚未完成两个真实多人客户端的断线实测。

除组件总开关外，上述更改先更新控制台草稿预览，点击「保存」后发布到 OBS；还原会恢复已保存画面。只读账号不能编辑。


### 队伍名称与颜色（0.5.1）

在「分队与选手池」选择「自定义队伍」，直接修改各池内的「队伍一/二名称」和「队伍一/二颜色」。名称与「赛事信息」中的左/右队名双向同步，颜色由拾色器选择。更改先显示在草稿预览，点击「保存」后播出，并随该输出配置持久化。

队伍颜色用于比分栏、阵容边框与标题、油量条和地图飞机标识；背景使用同色暗色调。低油量警示、死亡状态和导弹标识保留其状态颜色。切换到 DCS 红蓝阵营模式时使用原阵营配色，之前选择的自定义颜色继续保留，切回队伍模式恢复。各输出的颜色互不影响。


## 固定数量与元素缩放（0.6.0）

无选手数据时，阵容区不显示「等待选手数据」或「标牌已关闭」。开启「固定标牌数量（不足时保留空位）」后，每侧按设置的同时显示数补足空白标牌，不填入虚假的名称、油量或飞机数据。筛选结果不足、分页末页不足或完全没有数据时都保留空位；关闭则按实际可见人数收缩。数量 0 不生成空位。

在「固定席位与自由 Dock」点击「切换预览拖动」：

1. 拖动元素上方的标签来移动，拖动右下角角点分别调整宽、高。
2. 点击「整体组件 / 内部元素」切换编辑层级。整体模式可以调整比分栏、地图、队标、阵容组、单张标牌、导弹、事件和状态栏；内部模式从预览中的下拉列表选择队名、比分、计时、选手名称、机型、身份、油量标签/数值/条、速度、高度、武器等内容，再移动或缩放。
3. 移动和缩放默认吸附画布边线、中心及其他元素边线。按住 **Shift** 暂时取消吸附；操作中按下或松开立即切换。Shift 同时阻止将标牌拖入固定席位时自动绑定。
4. 修改先显示在控制台草稿预览，点击「保存」后播出。拖动/缩放单张流式标牌会将其放到独立 Dock，组内固定数量模式继续补空位。
5. 「恢复所有元素尺寸与内部位置」清除缩放和内部偏移；已有组件 Dock 位置仍通过「恢复自动位置」单独恢复。

尺寸按元素原始尺寸的 0.1～8 倍保存，随 1920×1080 画布同比适配预览与 OBS。内部元素跟随所属组件整体移动和缩放；重复武器、导弹和事件按显示位置编辑。隐藏或尚无内容的元素不产生空的编辑手柄。


## 选手选择小窗与来袭提示（0.7.0）

「分队与选手池」的「打开在线 / 历史选手小窗」在当前标签页打开浮动窗口。拖动标题移动，右下角调整尺寸；支持搜索，从列表拖入左右任一选手池，也可点击条目中的队伍按钮。已在另一池内的选手会换队，同池重复加入不增加席位。名单变更先预览，点击「保存」播出。

在线状态来自当前任务源新鲜的 Hook 玩家连接记录，观战中的已连接玩家同样可选。历史合并 Hook 保留的断线记录、飞机历史与本次控制台登录会话观察到的名单（会话缓存最多 512 名）；没有记录的更早连接无法回溯。刷新页面后从服务端仍保留的记录重新建立，退出登录清空会话缓存。链路失联或记录过期后不再标为在线，但不据此判定选手死亡。

新增五个「组件与数据开关」，均立即播出、自动保存且仅影响当前输出，默认开启：

- 小地图 · 导弹名称、小地图 · 发射人：分别显示导弹型号及发射时记录的选手/飞机名称，独立于小地图飞机标签。密集区域沿用标签避让，空间不足时省略文字，导弹图标仍保留。
- 标牌 · 来袭导弹图标：左侧标牌右外侧、右侧标牌左外侧显示，一发对应一个图标，无数量截断；超出卡片高度时向中央换列。
- 来袭导弹 · 名称、来袭导弹 · 发射人：分别控制图标旁的文字，关闭两者仍保留图标。未知发射者和来源冲突直接标明，不猜测身份。

来袭关联只使用完整快照内导弹 `targetObservation.status=object` 的当前 `object.entityId`，不使用历史目标或名称匹配；不受导弹列表的阵营/焦点过滤影响。目标切换、目标丢失、导弹移出快照会更新/移除对应图标；死亡、断线死亡、空席位和冲突席位不显示来袭提示。源离线、任务结束、链路中断或状态/快照年龄达到 3 秒时清空提示。该提示表示 DCS 当前报告目标，不代表导弹必然命中。提示整体可在预览「内部元素」中独立移动、缩放。

验证：`tests/threats.test.mjs`、`tests/threats-browser.mjs`，使用真实 C++/导播服务、已有 DCS 回放数据和合成目标切换，不是新增实机飞行测试。证据在 `runtime/verification/ui-player-threats/`。


## 取消预览与自适应绘制（0.7.1）

底部「保存」旁新增「取消」，撤回当前画面的全部未保存草稿（含布局、尺寸、筛选、选手池等），恢复最新已保存配置并退出预览编辑。已实时保存的功能开关不撤销。原「还原未保存更改」采用相同操作；保存或实时开关请求进行中需待完成后取消，避免与在途写入冲突。

Esc 在拖动/缩放手势中只取消本次手势；无手势时取消整个未保存预览。取消后不写入服务端，正式 OBS 输出保持已保存状态。「保存」仍保留编辑模式，便于继续调整。

元素尺寸继续沿用 elementLayouts 的 scaleX/scaleY，旧配置兼容。渲染改为实际内容框尺寸与等比布局缩放：文字、SVG 和图标保持纵横比例，宽高差异由可用内容区域及布局吸收，不再用 CSS scale 横纵拉伸成品。小地图重新计算投影、标签与像素缓冲，按实际显示尺寸和设备像素比绘制（单边最多 8192 像素、总计最多 16M 像素），避免沿用原始小画布放大。每次更新前恢复基础布局，防止遥测刷新累积缩放。

新上传队标优先保留最多 1024 像素边长，超出既有 75 KB 预算时逐级缩小与压缩；显示时保持原图比例。已保存的低分辨率队标不会生成原本不存在的细节，需要重新上传更清晰的原图。

验证包括取消草稿但保留实时开关、Esc 取消手势、尺寸持久化、Shift 吸附、连续刷新不漂移，以及 1×/2× DPR 地图像素分辨率。证据：runtime/verification/ui-adaptive-resize/。


## 移除原生状态栏与特写（0.8.0）

已移除原生状态栏开启/透明控制、F2 自动观战跟随、底部观战详情卡及「选手特写」布局。HOOK 0.3.2 不再注入 GUI 状态栏脚本，不读取 StatusBarDialog，不调用 LoSetCommand；仍为单文件任务采集 HOOK，保留 1 Hz 飞机/导弹采集、选手连接状态、事件缓存及 ACK。加载新 HOOK 需重启 DCS，既有进程内的旧脚本不会因覆盖文件而卸载。

C++ 0.4.1 与导播 0.8.0 已移除 camera-control 控制接口和命令转发。旧特写输出加载时迁移为比赛直播，保留输出 ID/地址、选手池、队伍、比分和其余设置，清除 followCamera、features.aircraft、底部卡片 Dock 及内部布局；普通输出同样清理这些废弃字段。新建服务默认只提供比赛直播、紧凑阵容两个画面。

「焦点飞机」只用于地图强调、阵容优先显示和导弹过滤，不产生独立特写卡片；不指定焦点时不会自动选第一架。原生 DCS 状态栏由游戏自身管理。浏览器链路状态组件仍保留。
